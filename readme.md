# TrafficSense-API

API untuk melayani prediksi model machine learning pada proyek Capstone Coding Camp 2026 powered by DBS Foundation & Dicoding Academy.

## 🚀 Fitur
- Prediksi berbasis model ML (klasifikasi lalu lintas).
- Endpoint API untuk integrasi aplikasi.

## 🛠 Teknologi yang Digunakan
- **Python**
- **Framework API**: [FastAPI / Flask]
- **Library ML**: [TensorFlow / YOLO]

## 📋 Struktur Folder
- `/models`: Menyimpan file model (.pt, .keras).
- `/services`: Logika bisnis dan pemrosesan data.
- `/utils`: Helper functions.
- `/venv`: Virtual environment.
